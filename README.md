# GameHours
Проект GameHours визуальная накрутка часов в стиме. 
Туториал по накрутке часов(Визуально)
после того как вы запустили SteamGH введите свой стим api создаете его на сайте https://steamcommunity.com/login/home/?goto=%2Fdev%2Fapikey 
и в поле домен пишите localhost и после получения ключа вводите его в поле ввода. 
далее ваш айди, запускаете стим - об аккаунте - и сверху в левом углу ваш айди вводите его также в поле ввода.
после чего вы указываете путь к вашему установленому стим. и после чего у вас появляется список игр
выбираете любую игру и меняее часы обязательно после смены нажимаете перезагрузить стим проверяйте!
